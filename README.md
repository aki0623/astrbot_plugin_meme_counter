# 表情包统计

按自然日统计群聊中图片、动图和平台表情的发送次数，并提供本群排行、个人次数和管理员重置命令。每天本地时间 00:00 会自动结算上一天的统计并发送到对应群聊，然后刷新为新一天数据。

## 命令

```text
表情统计 [数量]
表情包前五
表情排行 [数量]
我的表情
重置表情统计
```

## 说明

- 只统计群聊消息。
- 统计数据每天一结算，跨过零点后重新计算。
- 零点自动发送上一天的表情包统计结果。
- 默认统计 `Image`、`Face`、常见 GIF/动图文件和部分动图视频组件。
- 图片和动图会优先使用内容哈希识别，同一表情包即使临时 URL 不同，也会尽量归并为同一个。
- 内容读取失败时会回退到来源 URL/path 哈希。
- `表情包前五` 会用合并转发消息输出“表情包、次数”的 Top 5。
- 为了能在转发消息中还原图片表情，插件会保存图片来源；平台表情会以文本形式展示。

## 支持的表情来源

```text
Image        图片表情、部分平台贴纸
Face         平台内置表情
File         .gif / .webp / .apng / .tgs 等动图文件
Video        部分平台作为短视频传入的动图
```

## 统计口径

- 查询命令读取已缓存的当天统计，不会重新扫描历史消息。
- 插件启用前的历史表情包不会被补统计。
- 每个群独立统计，数据按自然日刷新。
